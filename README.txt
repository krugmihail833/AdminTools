Админ-тулс (клавиатура для админа Grand Mobile)
Сборка: Android Studio -> Open -> папка AdminTools -> Build > Build APK.
Или GitHub: загрузить проект в репозиторий -> вкладка Actions -> build -> скачать AdminTools-debug (APK).
Установка: открыть приложение, включить клавиатуру, выбрать её в поле ввода игры.
